# Image provenance

All delivered image files are served locally as optimized WebP, with `-small.webp` alternatives. No remote image hotlinks are required at runtime.

| Asset | Source | Use |
| --- | --- | --- |
| hero.webp | Original image generated for this fictional demo using ImageGen | Main garden concept, also used as project inspiration |
| plants.webp, lawn.webp, pavers.webp | Crops of the original generated garden concept | Category inspiration and garden details |
| mulch.webp | [Unsplash mulch collection](https://unsplash.com/s/photos/mulch), image `photo-1604176857875-cdbd7dfc3b7a` | Mulch category texture |
| soil.webp | [Unsplash compost collection](https://unsplash.com/s/photos/compost), image `photo-1492496913980-501348b61469` | Soil category inspiration |
| stone.webp | [Engin Akyurt on Unsplash](https://unsplash.com/photos/a-close-up-of-a-bunch-of-rocks-qtvTrX-Csc4), image `photo-1722677515459-9acadcdff042` | Natural stone category texture |

Unsplash photographs are provided under the [Unsplash license](https://unsplash.com/license). Product images are representative category photography, not an exact SKU representation. The site states this in both the catalog and detail dialogs. No images were taken from an existing client project.

Typography: DM Sans and Manrope, initially loaded from Google Fonts, with Arial/system fallbacks; the italic accent and wordmark use Georgia. Brand mark and service icons are original inline SVG.
